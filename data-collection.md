## Overview

The CBP Home application implements a multi-layered data collection infrastructure that captures comprehensive information about users, their devices, their behavior, and their personal relationships.

---

## Complete Data Collection Inventory

### Category 1: Location Data - CRITICAL

**What's Collected:**
- Precise GPS latitude and longitude
- Altitude information
- GPS accuracy (in meters)
- Continuous real-time updates

**Collection Method:**
- FusedLocationProvider API (Android's most accurate location service)
- Continuous background collection
- Always-on regardless of app usage

**Transmission Destinations:**
- Firebase Analytics (`app-measurement.com`)
- Government backend servers
- Linked with device identifiers for tracking

**Frequency:** Continuous (every few seconds to minutes)

**Data Use:**
- Real-time tracking of user location
- Movement pattern analysis
- Historical location database
- Geofencing and alerts
- Correlation with other datasets

**Privacy Impact:** Complete location history recorded indefinitely

---

### Category 2: Biometric Data - CRITICAL

**Facial Images:**
- Camera capture of complete face
- Multiple angles and lighting conditions
- Live biometric samples during verification
- Stored as image files on server

**Biometric Vectors:**
- Facial recognition feature vectors generated by iProov
- Mathematical representation of facial features
- Enables facial matching and identification
- More sensitive than photos

**Liveness Detection Data:**
- Motion tracking during face capture
- Eye movement patterns
- Head position and rotation data
- Used to detect spoofing attempts
- Also reveals behavioral patterns

**Transmission:**
- To iProov servers: `https://faceapi.regulaforensics.com`
- To Regula servers: `https://api.regulaforensics.com`
- To CBP backend systems
- Protocol Buffer serialized (binary format)

**Storage:** Indefinite retention by government and private companies

**Privacy Impact:**
- Face added to facial recognition databases
- Enables identification at airports, borders, public spaces
- Biometric data is non-revocable

---

### Category 3: Government Identification Documents - CRITICAL

**Document Types Scanned:**
- Passports (front and back)
- Driver's licenses
- National ID cards
- Travel permits
- Border crossing documents

**Data Extracted via OCR:**
- Full legal name
- Date and place of birth
- Nationality/citizenship
- Document number and type
- Issue and expiration dates
- Address information
- Passport issuing authority
- MRZ (Machine Readable Zone) data
- Signature (if present)

**Biometric Data from Document:**
- Photograph processed for facial recognition
- Facial features analyzed and vectorized
- Cross-referenced with live facial capture

**Transmission:**
- Regula Document Reader SDK: `https://api.regulaforensics.com`
- Processed images sent to Regula servers
- OCR results sent to CBP backend
- No encryption for sensitive data

**Storage:** Complete document images stored indefinitely

**Privacy Impact:**
- All identifying information in one place
- High-value target for identity theft
- Cross-referenced with government databases
- Enables tracking via identity document

### Category 4: Contact & Communication Data - CRITICAL

**Contacts Information:**
```
android.permission.READ_CONTACTS allows:
- All phone numbers
- All email addresses
- Contact names
- Contact photos
- Relationship tags
- Associated social media
- Instant messenger accounts
- Physical addresses
- Work information
```

**Call History:**
```
android.permission.READ_CALL_LOG allows:
- Every incoming call number
- Every outgoing call number
- Call duration
- Call timestamp
- Call type (missed, incoming, outgoing)
- Call log for entire history
```

**Network Inference:**
This data enables creation of complete social graph:
- Who you communicate with most
- Communication frequency patterns
- Time-of-day communication patterns
- Duration of conversations
- Groups of connected people
- Organization of your social network

**Transmission:**
- Firebase servers for aggregation
- Government backend systems
- Analysis systems for pattern matching

**Privacy Impact:**
- Your social network is exposed
- Contacts' privacy violated through your data
- Enables guilt by association tracking
- Identifies your closest relationships

---

### Category 5: Device Identifiers - HIGH

**Collected Identifiers:**
- Android Device ID (unique identifier)
- Android Advertising ID (if enabled)
- Firebase Installation ID
- IMEI (International Mobile Equipment Identity)
- Phone model and manufacturer
- Android OS version and security patch level
- Device serial number
- SIM card identifier

**Purpose:**
- Uniquely track the device
- Link all data to device identifier
- Enable device fingerprinting
- Cross-reference with other systems

**Persistence:**
- Device identifiers remain same across app uninstall/reinstall
- Survive factory reset for some identifiers
- Enable long-term tracking

**Privacy Impact:**
- All location data tied to device
- All biometric data linked to device
- Enables device-level profiling

---

### Category 6: User Activity & Behavior - HIGH

**Activity Recognition:**
```
android.permission.ACTIVITY_RECOGNITION allows detection of:
- Walking vs running
- Cycling
- Driving
- Stationary activity
- In-vehicle vs outdoor activity
- Transitions between activities
```

**Application Telemetry:**
- Screen time and app usage duration
- Feature interactions and clicks
- User journey through app
- Feature abandonment patterns
- Error frequency and types
- Session duration and timing

**Screen Usage Patterns:**
- Which screens visited in order
- Time spent on each screen
- Scroll patterns and content consumption
- Button clicks and interactions
- Form fill patterns

**Behavioral Profile Created:**
All this data enables creation of comprehensive behavioral profile

**Transmission:**
- Firebase Analytics (`app-measurement.com/a`)
- Sent periodically (every 1-3 hours)

**Privacy Impact:**
- Complete behavioral profile created
- Can be used for targeted analysis
- Enables predictive profiling

---

### Category 7: Crash & Error Reporting - HIGH

**Data Collected:**
- Application crash logs
- Error messages and stack traces
- Conditions leading to crashes
- Device state at crash time
- Memory usage patterns
- Battery information
- Network connectivity state
- Previous actions before crash

**Transmission:**
- Firebase Crashlytics: `firebase-settings.crashlytics.com`
- Sent automatically on crash
- Includes stack traces with method names

**Information Leakage:**
- May contain sensitive information
- Reveals internal app structure
- Shows API calls and data handling

**Privacy Impact:**
- Additional data about device and usage

| Documents | Indefinite | No | Government records retention |
| Contacts | Unknown | No | Likely retained indefinitely |
| Call Logs | Unknown | No | Likely retained indefinitely |
| Activity | Years | No | Typical analytics retention |
| Analytics | Years | No | Standard Firebase retention |
| Crash Logs | Unknown | No | Likely deleted after processing |

### What's NOT Clear

The Privacy Policy (if it exists) does not specify:
- How long data is retained
