# PDF Reports

Place your PDF report file in this directory with the filename:
**`CBP-Home-Security-Report.pdf`**

The website will automatically link to and serve this file from:
- Navigation bar: "📥 Download Report" button
- Sidebar: "Full Report" download section
- Homepage: Featured download section

## File Requirements

- **Filename:** `CBP-Home-Security-Report.pdf` (exact match required)
- **Location:** This directory (`assets/pdf/`)
- **Format:** PDF format (.pdf extension)

## How the Links Work

Once you add the PDF file to this directory:
1. GitHub Pages will serve it automatically
2. Users can click any of the download links to fetch the PDF
3. The links point to: `/cbp-warning-site/assets/pdf/CBP-Home-Security-Report.pdf`

## Notes

- Keep only the main report PDF in this directory
- The `.gitkeep` file ensures this directory is tracked by git even when empty
- If you remove the PDF, the download links will return a 404 error
