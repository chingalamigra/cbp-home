## If Must Continue Using: Minimize Risk

<div class="alert alert-info">
<h4>Harm Reduction Strategies</h4>
<p>If you must continue using CBP Home, these strategies can reduce (but not eliminate) risks:</p>
</div>

### Permission Management

**Revoke Unnecessary Permissions:**

After granting initial permissions, you can revoke suspicious ones:

1. Open Settings
2. Go to Apps > CBP Home > Permissions
3. Disable:
   - ✗ Contacts
   - ✗ Call Log
   - ✗ Activity Recognition (if possible)
   - ✗ Audio Recording
   - ✗ Camera (when not scanning documents)

**Keep Enabled:**
- ✓ Location (likely required for functionality)
- ✓ Camera (needed for ID scanning)
- ✓ Storage (needed for document processing)
- ✓ Internet (required for app functionality)

**Note:** Revoking permissions may disable app features.

### Location Tracking Reduction

**Disable When Not Using:**
1. Turn off Location Services when not actively using app
2. App cannot collect location data without permission
3. Re-enable only when specifically needed

**Use Approximate Location:**
- If app allows, use "Approximate Location" instead of "Precise Location"
- Limits tracking accuracy to ~1000 meters
- May reduce continuous tracking

**Geographic Masking:**
- Use VPN service to mask location
- Limitations:
  - App may detect VPN usage
  - Network may block VPN
  - Only partially effective
- Consider services like Mullvad, ProtonVPN

### Network Protection

**Monitor Network Activity:**
1. Use network monitoring apps to see data transmission
2. Look for suspicious connections
3. Document abnormal data flows
4. Report findings to privacy advocates

**Network Analyzer Apps:**
- Wireshark (advanced)
- TCPDump (advanced)
- Little Snitch (iOS alternative)
- Android Network Monitor

### Data Minimization

**When Using ID Scanning:**
1. Only scan absolutely necessary documents
2. Complete process as quickly as possible
3. Avoid scanning unnecessary documents
4. Don't keep app open longer than needed

**After Each Use:**
1. Clear app cache: Settings > Apps > CBP Home > Storage > Clear Cache
2. Revoke location permission if not using
3. Remove any stored documents
4. Close app completely
5. Disable background activity

### Device Isolation

**Separate Device Strategy:**
- Use older dedicated device only for CBP Home
- Don't use for other personal activities
- Don't store personal data on device
- Factory reset after major use
- Keep device offline except when using app

### Data Deletion

**Request Data Deletion:**
1. Contact CBP Privacy Office
   - Email: privacyoffice@cbp.dhs.gov
   - Formal FOIA/Privacy Act request
2. File FOIA request for your records
3. Request biometric data deletion
4. Keep records of requests

**Effectiveness:** Limited - government likely won't delete.

## Legal Options

### Understand Your Rights

**Fourth Amendment:**
- Protection against unreasonable searches
- Government must have warrant for searches
- Reasonable expectation of privacy
- Applicable to digital surveillance

**Privacy Act of 1974:**
- Protects personal information in government systems
- Allows you to access/correct records
- Restricts sharing of data
- Provides privacy protections

**First Amendment:**
- Protects freedom of association
- Protects freedom of religion
- Surveillance can chill these freedoms
- Chilling effect is unconstitutional

### Legal Action

**Potential Legal Challenges:**

- **Class Action Lawsuit:** Join or support
- **Individual FOIA Litigation:** Challenge denials
- **Constitutional Challenge:** Question legality
- **Regulatory Challenge:** Contest regulations

**Organizations Providing Legal Support:**
- ACLU
- Electronic Frontier Foundation
- Privacy International
- Constitutional Scholars

**Limitations:**
- Legal system is slow
- Government has broad authority
- Standing requirements limit who can sue
- Sovereign immunity provides government protection

## Summary: Decision Framework

### Should I Use This App?

```
┌─ Do I need CBP services?
│  ├─ NO → Don't install (RECOMMENDED)
│  └─ YES → Continue
│
└─ Can I use website or in-person instead?
   ├─ YES → Use alternative (RECOMMENDED)
   └─ NO → Continue

   └─ Can I use PreCheck/Global Entry instead?
      ├─ YES → Use alternative (RECOMMENDED)
      └─ NO → Continue

      └─ Must I use this app?
         ├─ NO → Don't install (RECOMMENDED)
         └─ YES → Continue

         └─ Can I minimize use?
            ├─ YES → Minimize permissions, use VPN, clear data
            └─ NO → Accept risks or find workaround
```

### Risk Acceptance Decision

Only you can decide if benefits justify risks:

**HIGH RISK, LIMITED BENEFIT:**
- Risk: Comprehensive surveillance of your life
- Benefit: Faster border crossing
- Recommendation: Not worth it

**Consider:**
- Your specific threat model
- Your vulnerability to misuse
- Your location/nationality/identity
- Your relationship to government
- Your access to alternatives
